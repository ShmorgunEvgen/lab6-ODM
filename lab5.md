Цілі лабораторної роботи

**Пошук надлишковості та аномалій:** виявлення потенційної надлишковості даних (наприклад, повторювані значення) або аномалій оновлення (проблеми вставки/оновлення/видалення) у поточній схемі.
**Перелік функціональних залежностей:** визначте та перелічіть функціональні залежності (ФЗ) для кожної проблемної таблиці.
**Перевірка нормальних форм:** оцініть поточну нормальну форму кожної таблиці (1NF, 2NF, 3NF) на основі її функціональних залежностей (ФЗ) та структури ключа.
**Застосування нормалізації:** перетворення таблиць у вищі нормальні форми (до 3НФ) для усунення часткових та транзитивних залежностей.

Залежності: id -> email name creation_time password_hash
Усі атрибути є атомарними, жоден неключовий атрибут не залежить лише від частини ключа і транзитивних залежностей немає, таблиця задовольняє критерій 3NF

tokens - 
Залежності: id -> token_value experation_time creation_time is_revoked user_id
Транзитивні залежності: token.id -> user_id -> users.email users.name users.creation_time users.password_hash
Усі атрибути є атомарними, і жоден неключовий атрибут не залежить лише від частини ключа.
Хоч у цій таблиці є транзитивна залежність, жоден із зв'язаних атрибутів міститься в самій таблиці, тому таблиця задовольняє критерій 3NF

wallet - 
Залежності: id -> name balance currency user_id
Транзитивні залежності: wallet.id -> user_id -> users.email users.name users.creation_time users.password_hash
Усі атрибути є атомарними, і жоден неключовий атрибут не залежить лише від частини ключа.
Хоч у цій таблиці є транзитивна залежність, жоден із зв'язаних атрибутів міститься в самій таблиці, тому таблиця задовольняє критерій 3NF

transations - 
Залежності: id -> amount creation_time wallet_id comment user_id
Транзитивні залежності: transactions.id -> user_id -> users.email users.name users.creation_time users.password_hash
                        transactions.id -> wallet_id -> wallet.name wallet.balance wallet.currency
Усі атрибути є атомарними, і жоден неключовий атрибут не залежить лише від частини ключа.
Хоч у цій таблиці є транзитивна залежність, жоден із зв'язаних атрибутів міститься в самій таблиці, тому таблиця задовольняє критерій 3NF

category - 
Залежності: id -> name type
Усі атрибути є атомарними, жоден неключовий атрибут не залежить лише від частини ключа і транзитивних залежностей немає, таблиця задовольняє критерій 3NF
